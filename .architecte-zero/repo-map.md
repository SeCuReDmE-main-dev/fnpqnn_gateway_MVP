# Repository map

- `fnpqnn_gateway_mvp/`: Python CLI, service, auth-policy, provider, token-governor, and MCP mechanisms.
- `tests/`: unit and contract evidence for supported mechanisms.
- `docs/public/`: catalog-facing public documentation.
- `docs/SECUREDME_EDUCATION_AUTH_ENFORCER.md`: canonical twelve-adapter authentication-policy boundary.
- `.codex/` and `.antigravity/`: host-specific, no-secret adapter templates.
- `infra/codeproject-ai/`: optional CodeProject.AI integration boundary.

Unknown-purpose files must be inspected before modification; names alone are not authority.
