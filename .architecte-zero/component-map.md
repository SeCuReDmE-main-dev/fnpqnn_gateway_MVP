# Component map

- Web-auth login wrapper: builds provider-native login instructions and validates no-secret boundaries.
- Suite auth enforcer: checks adapter drift and forbidden material across twelve repositories.
- Token governor: bounds model/tool capability after accepted authentication.
- Activation/bootstrap: persists reviewed non-secret routing state.
- MCP server: exposes typed operations without turning Markdown guidance into an executable claim.
- CodeProject.AI adapter: routes bounded backend operations; it is not a login mechanism.
